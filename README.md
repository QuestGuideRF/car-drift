## 📖 Описание проекта

**Car Drift Simulator** — это интерактивный симулятор физики автомобиля с реалистичной моделью дрифта, разработанный на Rust с использованием фреймворка [egui](https://github.com/emilk/egui/) для графического интерфейса. Проект демонстрирует использование нейронных сетей и эволюционных алгоритмов для обучения искусственного интеллекта управлению автомобилем на различных трассах.

### Ключевые возможности

- 🎮 **Интерактивная симуляция** — управление автомобилем в реальном времени с помощью клавиатуры или нейронной сети
- 🧠 **Искусственный интеллект** — обучение нейронных сетей для автономного управления
- 🏁 **Множество трасс** — различные предустановленные трассы с возможностью редактирования
- 📊 **Визуализация данных** — графики показателей в реальном времени (скорость, ускорение, угол поворота и т.д.)
- 🔧 **Настраиваемая физика** — тонкая настройка параметров физической модели (сцепление, трение, ускорение)
- 🧬 **Эволюционные алгоритмы** — использование CMA-ES и дифференциальной эволюции для обучения
- 🎨 **Редактирование трасс** — создание и модификация собственных трасс прямо в интерфейсе

## 🚀 Установка

### Требования

- **Rust** 1.70 или новее ([установка](https://www.rust-lang.org/tools/install))
- **Trunk** (для сборки веб-версии, опционально)
  ```bash
  cargo install --locked trunk
  ```

### Установка зависимостей для Linux

#### Ubuntu/Debian:
```bash
sudo apt-get install libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev libxkbcommon-dev libssl-dev
```

#### Fedora:
```bash
sudo dnf install clang clang-devel clang-tools-extra libxkbcommon-devel pkg-config openssl-devel libxcb-devel gtk3-devel atk fontconfig-devel
```

### Клонирование репозитория

```bash
git clone <repository-url>
cd car_drift-main
```

## 💻 Использование

### Нативный запуск (десктоп)

```bash
cargo run --release
```

### Веб-версия (WASM)

1. Установите WASM target:
```bash
rustup target add wasm32-unknown-unknown
```

2. Запустите локальный сервер разработки:
```bash
trunk serve
```

3. Откройте в браузере:
```
http://127.0.0.1:8080/index.html#dev
```

> **Примечание**: Параметр `#dev` в URL отключает кэширование для разработки.

### Производственная сборка для веб

```bash
trunk build --release
```

Собранные файлы будут в директории `dist/`, которую можно загрузить на любой хостинг статических сайтов (например, GitHub Pages).

## 🎯 Особенности

### Управление

- **Стрелки влево/вправо** — поворот колес
- **Стрелка вверх** — ускорение вперед
- **Стрелка вниз** — торможение/задний ход
- **Пробел** — дополнительное ускорение
- **Escape** — сброс позиции автомобиля
- **Колесо мыши** — масштабирование камеры
- **Средняя кнопка мыши** — перемещение камеры

### Режимы работы

1. **Ручное управление** — управление автомобилем с клавиатуры
2. **Управление нейронной сетью** — автономное управление обученной нейронной сетью
3. **Запись действий** — запись ваших действий для обучения сети

### Настройки

- **Параметры физики**: коэффициент сцепления, трение, ускорение, ограничение скорости
- **Параметры симуляции**: количество шагов, настройки награды, физические упрощения
- **Параметры интерфейса**: размер холста, масштаб вида, количество точек на графиках

### Редактирование трасс

1. Откройте раздел "Edit track" в интерфейсе
2. Включите режим редактирования
3. **ЛКМ** — добавление точки на трассу
4. **ПКМ** — удаление точки или вставка точки между существующими
5. **Перетаскивание** — перемещение точек
6. Кнопка "Print track" выводит код трассы в консоль
